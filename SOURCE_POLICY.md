# Source Policy

This repository is a **public engineering showcase**, not a source distribution repository.

## Public

- project overviews
- feature summaries
- runtime validation notes
- architecture-level documentation
- limited non-sensitive code excerpts
- TradingView screenshots / evidence
- public-safety CI

## Private

- complete Pine Script implementations
- full signal logic
- internal helper functions
- Python reference implementations that reproduce proprietary logic
- private regression suites tied to full source

## Review access

Full source may be reviewed privately during legitimate project discussions when appropriate.

## Licensing

No license is granted to copy, redistribute, resell, or reuse the private production implementations from this showcase.
